# Testing Atsuko Hub 1.5.0

This file says what was tested, how, and what is left for a person with Roblox. Nothing in the manual tables below has been ticked by the author. Every row starts as `[not run]` and only a human with an executor can change it.

## 1. What "tested" means here

| Level | Meaning | How it was reached in this build |
|---|---|---|
| L0 syntax | every `.lua` file parses | `Testing/tools/luau.py check <file>` (a Luau parser written for this project; it also reports local and upvalue limits). The official `luau-analyze` could not be installed in the build environment, so L0 here is **not** the official analyzer. Run `luau-analyze --mode=nocheck` on your own machine if you want that second opinion. |
| L1 static rules | grep-level rules hold | `Testing/static_checks.py` |
| L2 logic | pure logic and mock-GUI behaviour give the right answers | `Testing/tools/minilua.py` runs the suites in `Testing/tests/` on a small Lua interpreter written for this project. It is **not** Roblox and **not** the official `luau` CLI, so a pass means "the logic is right", never "it works in game". |
| L3 in-game self-test | code runs inside Roblox without errors | the hidden `selftest` command (arrives with the self-test module); results must be pasted back by someone who has Roblox |
| L4 manual | a human tried it | the tables in section 4 |

Roblox could not be run while this was built. Everything that touches real Roblox behaviour (animation, input, layout engine, executors) is L0 to L2 only until you run section 4.

## 2. Run the offline checks (needs only Python 3)

From the folder that contains `Hub/` and `Testing/`:

```
python3 -I Testing/tools/minilua.py run . Testing/tests/*.lua
python3 -I Testing/tools/luau.py check Hub/AtsukoHub.lua Hub/modules/*.lua
python3 -I Testing/static_checks.py
python3 -I Testing/check_no_comments.py
python3 -I Testing/validate_credits.py
python3 -I Testing/validate_credits.py --selftest
python3 -I Testing/verify_patches.py --only reanimation --originals <folder with the original FDless.txt, Reanimation.lua.txt and betabetafork.txt>
python3 -I Testing/verify_patches.py --only main --zip <your Main Scripts.zip>
```

The first command prints one line per suite (passed / failed counts) and `TOTAL FAILURES: 0` when everything holds. The second prints one line per file; a file that does not parse prints the line and column. The third checks the rules that can be checked by reading the files (versions agree, no emoji, the line limit, the four reanimations, every manifest path exists, no touch-button pad or aim cross or in-script alignment panel in a shipped script, no stock Roblox notice outside the notice router, an alignment adapter in every patched Main Script, Last Star keeping its three phone controls) and lists the rules that can only be checked once a later part is built. The fourth fails when a comment appears that was not in the v1.3.0 package, the three third-party reanimations or the Main Scripts (`Testing/baseline_v1.3.0.txt` holds fingerprints of those; build it again with `--build-baseline`). The fifth and sixth undo each patch on the shipped file (first the three reanimations, then the six Main Scripts) and must give back the original byte for byte. They also check that every hunk of a Main Script patch lies inside one of the blocks named in `Testing/patch_blocks.json` (the removals the owner asked for and nothing else).

## 3. Run the hub from your own folder (no GitHub)

1. Put the whole `Atsuko Hub` folder inside your executor's `workspace` folder so that `workspace/Atsuko Hub/Hub/AtsukoHub.lua` exists.
2. Run `loadstring(readfile("Atsuko Hub/Hub/AtsukoHub.lua"))()`.
3. Expected: the start toast says "from your folder" and Settings > About shows the same. Nothing is fetched from GitHub. The Scripts list is built from the `Scripts/` folder next to `Hub/` (needs `listfiles` and `isfolder`; without them the hub still starts and says why the list is empty).
4. `-reload` reads the file from the folder again. Rejoin and serverhop bring the hub back from the folder.
5. A different folder name: run `getgenv().AtsukoLocalRoot = "My Folder"` first. `getgenv().AtsukoLocalRoot = false` forces the GitHub copy.
6. If the game closes while the hub loads, the next start is in safe mode (a toast says so) and `AtsukoHub/boot.json` names the last step. Paste that text and the red lines of the F9 console back to the author.
